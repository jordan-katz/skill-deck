Reading this deck

What the columns mean and why the effect column exists.

Every row is something you can type. Click the command to copy it. The uses number opens the tree of what that command delegates to, so you can see the blast radius before you run it.

ColumnWhat it tells you
effectHow far the blast radius goes, from reads-only to changes-things-outside-the-repo.
runsWhether the agent can reach for it on its own, or only when you type it.
argumentWhat to put after the command. Square brackets are placeholders.
usesHow many other skills, agents or servers it pulls in.
correctionThe effect column is a judgment you write in your config, not something the tool can infer. An unreviewed deck will say build for everything.

Make it yours

Three commands and one file.

Point sources.json at your config, then sync and build. The skills-dir adapter needs nothing but a skills directory, so most setups work without writing any code.

git clone <this repo> skill-deck
cd skill-deck
$EDITOR data/sources.json    # set path to your config
node scripts/sync.mjs
node scripts/build.mjs

Then open index.html. If you have Claude Code, skip the editing step: ask it to set up the skill deck for your config and it will read skills/deck-setup/SKILL.md and wire it up, including writing blurbs that read as English rather than as model trigger text.
